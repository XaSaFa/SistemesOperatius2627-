# Fonts i bibliografia

## Documentació curricular (Generalitat de Catalunya)

- **Decret 193/2013, de 9 de juliol**, pel qual s'estableix el currículum del cicle formatiu de grau mitjà de
  Sistemes Microinformàtics i Xarxes (DOGC). Modificat per l'Ordre EDU/186/2021.
- **Document IC10 — Orientacions als centres educatius** per organitzar el cicle de grau mitjà de SMX
  (Departament d'Educació). Conté els resultats d'aprenentatge, criteris d'avaluació i continguts de cada mòdul.
- Fitxers de treball d'aquest projecte:
  `Documentació oficial SMX/DOGC_T_sistemes_microinformatics_xarxes.pdf`,
  `Documentació oficial SMX/mp_IC10_sistemes_microinformatics_xarxes_20240424.docx`.

## Llibre de text de referència

- **Muñoz López, Francisco Javier.** *Sistemas operativos monopuesto*. Ciclo Formativo de Grado Medio.
  McGraw-Hill / Interamericana de España, 2013. ISBN 978-84-481-8553-4.
  Fitxer: `Sistemes operatius/CFGS_Sistemas_operativos_monopuesto.pdf`.
  Estructura en tres blocs: unitats 1-5 (fonaments de sistemes informàtics i SO), unitats 6-10 (Windows),
  unitats 11-14 (GNU/Linux, distribució Ubuntu).

## Llibre complementari (nivell CFGS)

- **Administración de Sistemas Operativos** (Ra-Ma). Fitxer:
  `Sistemes operatius/CFGS - Administracion De Sistemas Operativos (Ra-Ma).pdf`.
  És un PDF **escanejat sense capa de text**; per aprofitar-lo caldria aplicar-hi OCR. Correspon a un mòdul
  de grau superior (administració de SO en xarxa), de manera que només és un suport puntual per a aquest mòdul de grau mitjà.

## Documentació oficial de fabricants (actualització de continguts)

Els llibres descriuen versions antigues (Windows XP/7, Ubuntu 11.10). El contingut d'aquesta base de
coneixements s'ha contrastat i actualitzat amb:

### Microsoft
- **Microsoft Learn — Windows client documentation** — <https://learn.microsoft.com/windows/>
- **Windows 11 requisits del sistema** — <https://learn.microsoft.com/windows/whats-new/windows-11-requirements>
- **Referència de comandes de Windows** (`cmd`, `diskpart`, `sfc`, `dism`, `bcdedit`, `schtasks`, `net user`…) —
  <https://learn.microsoft.com/windows-server/administration/windows-commands/windows-commands>
- **PowerShell documentation** — <https://learn.microsoft.com/powershell/>
- **Emmagatzematge — Administració de discos i sistemes de fitxers (NTFS, ReFS, exFAT)** —
  <https://learn.microsoft.com/windows-server/storage/>
- **Hyper-V a Windows 10/11** — <https://learn.microsoft.com/virtualization/hyper-v-on-windows/>

### GNU/Linux
- **Pàgines de manual de Linux (`man`)** — <https://man7.org/linux/man-pages/> (`chmod(1)`, `chown(1)`,
  `useradd(8)`, `passwd(1)`, `ps(1)`, `kill(1)`, `crontab(5)`, `systemd(1)`, `systemctl(1)`, `mount(8)`, `fstab(5)`).
- **Ubuntu Server / Desktop documentation** — <https://documentation.ubuntu.com/> i <https://help.ubuntu.com/>
- **Debian Administrator's Handbook** — <https://www.debian.org/doc/manuals/debian-handbook/>
- **Red Hat Enterprise Linux — System administration guides** — <https://docs.redhat.com/>
- **The Linux Documentation Project — Filesystem Hierarchy Standard (FHS)** — <https://refspecs.linuxfoundation.org/fhs.shtml>
- **Arch Wiki** (referència tècnica ràpida sobre systemd, GRUB, particions GPT) — <https://wiki.archlinux.org/>

### Virtualització
- **Oracle VirtualBox — User Manual** — <https://www.virtualbox.org/manual/>
- **VMware Workstation Player / Pro documentation** — <https://docs.vmware.com/>
- **KVM / libvirt** — <https://libvirt.org/docs.html>
