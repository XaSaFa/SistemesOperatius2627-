## Idees força del bloc

- Abans d'instal·lar, cal **comprovar que el maquinari compleix els requisits** del SO i que hi ha
  **controladors** per a tots els components.
- Un disc nou només té estructura física: cal **particionar-lo** i **formatar-lo** (donar-li un sistema d'arxius).
- Convé separar el **sistema** de les **dades** en particions diferents.
- La instal·lació segueix tres fases: **planificar → instal·lar → documentar**.
- El **gestor d'arrencada** (Windows Boot Manager / GRUB) permet triar el SO en encendre l'equip.
- Cal respectar les **llicències** del programari i **actualitzar** el SO des del primer dia.
